# Requirements
- 1 pcs esp32 32 pins
- 2 8 channel relay
- 1 ds3231 rtc module + cr2038 battery
- 20 F-F Dupont Wires

# Installation
> download and Flash the firmware to offset `0x0`
- https://github.com/xiv3r/esp32-timer-switch/raw/refs/heads/main/esp32-dump-0x0.bin

# Wifi Key
- SSID: ESP32-TIMER-XXXX
- PASSWORD: esp32relay
